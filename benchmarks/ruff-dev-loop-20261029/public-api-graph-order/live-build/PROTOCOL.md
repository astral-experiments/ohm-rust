# Live Ruff build time on the proposed compiler

The exact 569aefbe to 6ab241bb graph-order change saved 0.488% dirty compiler instructions but increased the complete Cargo time by 2.51% in a prior 20-pair study. That study restored a complete authentic pre-edit state per sample. This separate comparison tests 24 consecutive edit/revert cycles in four persistent ordinary Cargo targets. An independently rematerialized pair per compiler helps quantify the installation-to-installation variability. Levels of instruction count and elapsed time from different source revisions or protocols stay independent.

Use signed Ohm -19 Cargo and stock Wild, same Rust driver launcher, LLVM and standard files, exact SDK manifests, cores 4–7. Use the 88d851449d production line-ending edit on Ruff 93526150, with its unchanged regression test in the checkout. Initialize physical roles in A1, B1, B2, A2 order. Each has its own isolated source overlay, installed compiler, local/central Cargo paths and registry overlay at the same canonical guest paths. Retain all four installations and targets at the same inodes through completion. Inside each target write one production file in place, execute the ordinary build, execute its unchanged repeat, then move to the next assigned installation. Never copy or restore the cargo output trees during measured work. Run all four installations in every direction before reversing. Forward order uses all 24 four-way permutations exactly once in a fixed pseudorandom order with seed 2611029. Reversal independently shuffles all permutations with seed 2611030.

Before sampling, each installation must show one real root compiler and zero linkers after a forward and reverse build, zero after their unchanged repetitions, complete historical regression-test inventory of 13, old test exit 101 and new exit 0, and correctly different old/new outputs matching their respective independent empty-root build and the other three installations. Compare raw ELF/metadata bytes and all bytes of the library archive except its verified member-name nonce. Validate ordered linker/member tables before normalization. Each measured dirty Cargo roster must match its native reference. Each unchanged repeat must report only fresh units and reproduce identical raw output bytes. Collect unwrapped time from launch of Cargo to exit and complete wait4 child CPU, page faults and involuntary/voluntary context switches. Parse, hash, save and compare outside that timer.

The primary endpoint is ordinary whole-Cargo forward-dirty wall time. One unit of statistical analysis is a four-lane block. Average each compiler's pair of log wall times before taking the difference and keep all completed blocks. Report the paired percent saving, fixed-seed 50,000-resample percentile interval and two-sided sign test; positive values indicate speedup. Secondary diagnostics are the reverse edit, unchanged repeats, child CPU, faults/switches and both installation-pair savings and within-compiler physical contrasts. A 95% interval crossing zero is inconclusive. Within ±1.0% means the full elapsed interval falls inside that range; results for the other protocol continue to be disclosed. A new source PR or release requires repeatable ordinary-user benefit with no established regression. No early stopping, no sample exclusions. A failed admission invalidates the study and keeps the failed receipts.
