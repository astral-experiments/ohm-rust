# Generic-export metadata summary: uv library test harness

The original first block and an independently authorized inverse replication on a fresh host measure **all final Callgrind instructions in one uv library test-harness rustc process**, including its worker threads and excluding child linker counters. Each block independently passed the same predeclared eight-pair gate. The original fixed-host endpoint was interrupted; the two results are reported separately, without pooling. This is not a Cargo whole-command or wall-time result.

The baseline is the archived optimized #219 developer compiler with embedded SDK12 commit `f93a752e`; the candidate embeds its authentic measured commit `0a72d981`. They use the same optimized build recipe and pinned LLVM, with independently compatible std and dependency banks. The different compiler identities can change StableCrateId and generic-provider selection. This comparison therefore does not fully isolate the source optimization from that identity difference. A separately frozen identity control and an authentic-edit native endpoint are not included in this packet.

Each block has eight fixed pairs, 200,000 log-ratio bootstrap resamples and its own fixed seed. All eight pairs must improve and the lower 99% reduction bound must exceed 0.1% in each block. Orders are balanced and inverse across blocks. There is no pooled qualification gate, deleted pair, sample extension or retry of a valid failure. Higher-count pairs remain included. `paired-counts.csv` contains every paired integer count; order-specific statistics are in the two result files.

In the first pair, the direct CrateInfo-to-full-generic-list edge fell from 480 calls / 995,103,266 inclusive instructions to one call / 124,286 instructions, alongside 479 boolean queries / 685,946 instructions. The difference in those **sibling** edges accounts for 97.3% of that pair's total reduction. The nested external providers changed from 479 full lists to zero, with 479 boolean reads; their nested costs are not added again. `first-pair-mechanism.json` retains the exact counters and source-profile hashes. This attribution is descriptive for that pair.
